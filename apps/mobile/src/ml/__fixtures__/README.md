# Runtime test fixtures

Synthetic models for `runtime.test.ts`, never trained on real recordings: random weights or random
numbers only, made with onnx 1.23.1, lightgbm 4.7.0, skl2onnx 1.20.0 and onnxmltools 1.16.0.

| File                                | What it is                                                                                                                                                                                                                                                                                                  |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `rhythm-lgbm-fixture.onnx`          | LightGBM, 4 trees, 3 classes, fitted on 300 random 8-feature rows; skl2onnx with the onnxmltools LightGBM converter, `zipmap=False` (a stand-in for tree models in general; Track D's real export outputs only `probs`). Input `features` [N, 8]; outputs `label` int64 and `probabilities` float32 [N, 3]. |
| `rhythm-lgbm-fixture.expected.json` | One feature row and LightGBM's own `predict` / `predict_proba` for it.                                                                                                                                                                                                                                      |
| `sqi-fixture.onnx`                  | `pClean = sigmoid(mean(window))`, input `window` [1, 1, 256], output `pClean` [1, 1].                                                                                                                                                                                                                       |
| `sqi-slow-fixture.onnx`             | Same interface, plus a 3072 × 3072 matmul built from the input, so one run takes far longer than 50 ms.                                                                                                                                                                                                     |
| `diabetes-fixture.onnx`             | `pPattern = sigmoid(mean(beat) + mean(shapeFeatures) + mean(hrSummary))`, inputs [1, 1, 256], [1, 12], [1, 4].                                                                                                                                                                                              |
